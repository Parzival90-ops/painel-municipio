# Painel do Município — Selo UNICEF 2025-2028

Simulação de acompanhamento das entregas do Selo UNICEF 2025-2028 nos municípios do Maranhão e do Piauí. **Não é a pontuação oficial do UNICEF e não é um canal oficial do UNICEF.**

Página: https://parzival90-ops.github.io/painel-municipio/

- `index.html`: a página.
- `app.js`: o funcionamento da página.
- `dados.json`: os dados por município, substituídos a cada atualização.

Os arquivos são gerados pela automação de monitoramento. Não edite à mão.
